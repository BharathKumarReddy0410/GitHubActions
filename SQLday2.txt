--------------
having is used to filter groups after group by clause.


Difference between Where and Having Clause
-------------------------------------------

where clause                                   having clause
-------------                                  --------------
where is used to filter rows              having is used to filter groups
where clause used before group by          having used after group by
where cannot use aggregate functions       having used aggregate functions

GROUP BY

GROUP BY groups rows having the same values and is generally used with aggregate functions.

Syntax:

SELECT column_name, aggregate_function(column_name)
FROM table_name
GROUP BY column_name;

HAVING Clause

HAVING is used to filter groups after GROUP BY.

Syntax:

SELECT column_name,
aggregate_function(column_name)
FROM table_name
GROUP BY column_name
HAVING condition;

Interview Theory Questions
31. Which clause is executed first?

Execution Order:

FROM
WHERE
GROUP BY
HAVING
SELECT
ORDER BY

32. Can WHERE clause contain aggregate functions?

No.

Because WHERE filters rows before grouping. Aggregate functions are calculated after GROUP BY.

33. Difference between COUNT(*) and COUNT(column_name)

COUNT(*)

Counts all rows.
Includes rows containing NULL values.

COUNT(column_name)

Counts only non-NULL values.


34. What happens if HAVING is used without GROUP BY?

It is valid.

Example:

SELECT AVG(salary)
FROM employees
HAVING AVG(salary)>50000;


35. Difference between MAX() and ORDER BY DESC LIMIT 1

MAX()

Aggregate function.
Does not sort data.
Returns maximum value.

ORDER BY DESC LIMIT 1

Sorts rows.
Returns first row after sorting.

MAX() can work on numbers, strings and dates.


36. Which aggregate functions ignore NULL values?

All aggregate functions except COUNT(*) ignore NULL values.

Examples:

SUM()
AVG()
MIN()
MAX()
COUNT(column_name)


37. Difference between WHERE and HAVING
WHERE	HAVING
Filters rows	Filters groups
Used before GROUP BY	Used after GROUP BY
Cannot use aggregate functions	Can use aggregate functions



38. Can multiple columns be used in GROUP BY?

Yes.

SELECT department, city, COUNT(*)
FROM employees
GROUP BY department, city;



39. Can GROUP BY be used without aggregate functions?

Yes.

SELECT department
FROM employees
GROUP BY department;

Equivalent to:

SELECT DISTINCT department
FROM employees;


40. Why can't non-grouped columns be selected with GROUP BY?

Because SQL doesn't know which value to choose from each group.
