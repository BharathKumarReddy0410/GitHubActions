Scenario 1: User Login Module

The application provides a login page for registered users. The page contains a Username field, Password field, Login button, and a "Forgot Password" link. Username and Password are mandatory fields. Password should be masked while typing. Users with valid credentials should be redirected to the dashboard after successful login. Invalid credentials should display an appropriate error message. The application should support multiple attempts and maintain session security.

Scenario 2: User Registration Module

The application allows new users to register by providing First Name, Last Name, Email Address, Mobile Number, Password, and Confirm Password. All fields are mandatory. Email address should be unique. Password and Confirm Password must match. Upon successful registration, the user should receive a confirmation message and be able to log in using the newly created account. Appropriate validations and error messages should be displayed for invalid inputs.
