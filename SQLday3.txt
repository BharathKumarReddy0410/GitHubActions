having clause:
--------------
having clause is used to filter groups after aggregate functions  sum(), min(), max(), count(), avg();


Q1.
Find departments having more than 5 employees.
select department, count(*)  as Emp_count from Employees group by department having count(*)>5;

Q2.
Find customers whose total order amount is greater than 10000.
select customerId, sum(amount) as Total_amount  from orders group by customerid having sum(amount)>10000;


Case Statement:
-----------------
it works like if-else statement  in sql

select Emp_name,salary,
       case
           when salary>=100000 then 'High'
           when Salary>=50000 then 'Medium'
           Else 'Low'
       End AS salary_category
       from employees;

Q2.
Categorize orders:

'Large' if amount > 5000
'Medium' if amount between 2000 and 5000
'Small' otherwise

select customerid, sum(amount) as orders_amount,
      case
          when sum(amount)>5000 then 'Large'
          when sum(amount)>=2000 and sum(amount)<=5000 then 'Medium'
          Else 'Small'
          End as orderCategory
     from orders
       group by customerid;

Order By:---
-------------------------------
order by is sued to sort the  result set into ascending or descending order
 By default order by gives Ascending order
 i we want to sort th result set in descendoing order used desc keyword;


Display employees sorted by salary in ascending order.
select * from employees order by salary;


Display employees sorted by department and then by salary in descending order.
select * from employees order by department, salary desc;


Distinct:--------
-----------------------------------
it removes duplicate values form the result;


find all unique departments from the Employees table.
select Distinct department from employees;

Find unique customer IDs from the Orders table.
select Distinct customer_id from orders;

1. Display all unique departments.
select distinct department from employees;


2. Display employees sorted by salary in descending order.
select * from employees order by salary desc;

3. Display employees sorted first by department and then by salary descending.
select * from employees order by department ASC,salary desc;
